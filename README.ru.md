## Что уже умеет

- Окно приложения в три колонки; тёмная и светлая темы меняют всё окно целиком;
  окно без рамки со своей шапкой и перетаскиванием.
- Чат с движком OpenCode: ответ печатается в ленту постепенно; код — с
  подсветкой и кнопкой «Копировать», значимые ответы показывают «Sources used»
  со ссылками на файлы.
- Приветственная сборка: счётчики проекта, сценарии быстрого старта, модели;
  группы чатов «Сегодня / Вчера» в сайдбаре.
- Плагины: каталог «Available» с поиском и установкой, сводка прав перед
  включением, команды плагина кнопками в шапке, автообновление при запуске.
- Права по категориям (чтение/запись/сеть/терминал: разрешить / спрашивать /
  запретить) — в панели Configure у карточки плагина; и в настройках для всех.
- Разы подключения: на один раз, на чат, на проект, глобально; Tool Sets —
  группы плагинов одним пунктом; избранное и недавние в меню «+».
- Раздел «Плагины»: карточки с действиями включить/выключить/удалить,
  активность вызовов и счётчики.
- Сравнение моделей с opencode.ai: цены за миллион токенов, бенчмарки,
  «Выбрать» меняет модель чата или модель по умолчанию.
- Настройки: тема и язык, модель по умолчанию, ключи провайдеров
  (Диспетчер учётных данных Windows), права по умолчанию, папка данных.
- Чат, тема, папка проекта и настройки переживают перезапуск приложения;
  сессия движка продолжается; одна команда проверяет весь продукт.

## Как запустить

Нужны Windows 10/11 x64, Node 22 и npm, Rust (rustup), Python 3.13 с Pillow
и OpenCode CLI для ядра.

```bash
npm install
npm run tauri dev    # открывает окно приложения
```

Проверить всё разом: `npm run check`. Полный набор проверок: `python -X utf8 tools/run_checks.py`.
Собранные копии для запуска без разработки кладутся в `builds/`.
