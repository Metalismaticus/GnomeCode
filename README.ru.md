## Что уже умеет

- Окно приложения в три колонки; тёмная и светлая темы меняют всё окно целиком.
- Чат с движком OpenCode: ответ печатается в ленту постепенно; строки вызовов
  инструментов и обрыв связи — тоже строки в ленте, а не тишина.
- Выбрать папку проекта, листать её файлы в панели и прикрепить файл к вопросу.
- Плагины из чата: меню «+» открывает Connect plugin, команды плагина встают
  кнопками в шапку, каждая команда спрашивает одобрение при первом
  использовании (Разрешить / Разрешить для этого чата / Отказать).
- Чат, тема и папка проекта переживают перезапуск приложения; сессия движка
  продолжается.
- Одна команда проверяет весь продукт; собранная копия ложится в `builds/`.
<!-- studio:end features -->

<!-- studio:begin run -->
## Как запустить

Нужны Windows 10/11 x64, Node 22 и npm, Rust (rustup), Python 3.13 с Pillow
и OpenCode CLI для ядра.

```bash
npm install
npm run tauri dev    # открывает окно приложения
```

Проверить всё разом: `npm run check`. Полный набор проверок: `python -X utf8 tools/run_checks.py`.
Собранные копии для запуска без разработки кладутся в `builds/`.
