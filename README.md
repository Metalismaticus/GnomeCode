# GnomeCode

Лёгкий Windows-клиент OpenCode: чат со стримингом, плагины «в два клика»
с правами и скоупами, сравнение моделей, статистика расхода, MCP-серверы
и свои скиллы.

## Установка

1. Скачайте `setup.exe` (или zip) из Releases репозитория.
2. **SmartScreen**: при первом запуске Windows может показать «Система
   Windows защитила ваш компьютер» — приложение не подписано сертификатом.
   Нажмите **Подробнее → Выполнить в любом случае**.
3. Запустите GnomeCode. Движок `opencode` должен быть установлен
   (desktop-версия или CLI) — приложение найдёт его само.

Где данные: `%APPDATA%\com.gnomecode.app\data` (состояние окна, реестр
плагинов, правила, кэши) — удаляется вместе с удалением приложения.
Аутентификация моделей — собственная у opencode (GnomeCode её переиспользует
и не хранит дубликатов ключей; ключи провайдеров, заданные в настройках
GnomeCode, лежат в Windows Credential Manager).

## Скиллы

Настройки → «Скиллы»: свои команды-инструкции движку (markdown-файлы в
`config/opencode/command/`). Скилл = имя, описание и текст инструкции;
после сохранения появляется кнопкой в шапке чата.

## MCP-серверы

Настройки → «Плагины» → «MCP-серверы»: список секции `mcp` вашего
opencode.json, включение/выключение, добавление local (команда) и remote
(адрес). Правка перезапускает движок.

## Приватность

- Событийный счётчик — **opt-in**: выключен по умолчанию, включается
  тумблером в Настройках → «Плагины». Данные — локальный JSONL в папке
  данных, **без сети**: установки, обновления, откаты, вызовы команд,
  чат-сессии. Ничего не уходит с машины.
- Ключи провайдеров — Windows Credential Manager.
- Каталог плагинов и модели — публичные списки с raw.githubusercontent и
  models.opencode.ai (только чтение).

## Удаление

Удалите приложение и папку данных
`%APPDATA%\com.gnomecode.app\data` — ключи в Credential Manager
(записи `GnomeCode/*`) при желании тоже.
