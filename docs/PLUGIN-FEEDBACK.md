# Уроки процесса — предложения правок плагина

Чат разработки записывает уроки партии, которые касаются самого плагина
studio (не проекта): команда или агент сделал/не сделал что-то(process), что
тексту нуженак поправка. Владелец переносит строки в репозиторий плагина;
плагин из этого файла не редактируется.

Формат строки: `<дата> — <команда/агент> — <что случилось> — <предлагаемая
правка текста>`.
