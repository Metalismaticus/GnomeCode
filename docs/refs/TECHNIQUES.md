# Свои приёмы

Приёмы стилизованного вида, найденные для этого проекта. Сюда агент `reference`
(режим «концепт: приём», зовёт `/studio/idea`) дописывает то, чего нет в библиотеке
плагина `reference/LOOK_TECHNIQUES.md`, и рецепты под наш стек; паспорта тем
ссылаются на приём по имени: «У нас: приём: <имя> · <где в коде>». Отдельный
файл: библиотеку не копирует и с ней не сливается; `/studio/setup обновить` кладёт,
если нет. Способ = приём отсюда или из библиотеки; «смена способа» — следующий
приём из строки паспорта, не «придумать».

Продукт интерфейсный: группы — компоновка, цвет и тон, типографика,
состояния и анимация интерфейса (не мировые свет/дымка/вода).
