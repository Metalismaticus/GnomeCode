## Проверяемые утверждения
1. Главное впечатление: светлое техничное рабочее место из плотных столбиков —
   сайдбар с быстрыми действиями, лента истории по датам, разбор в центре и
   панель проекта справа; каждая строка несёт две линии информации, и глаз без
   поиска находит чат, папку и разрешение чата.
2. Светлая гамма холодная: фон белый, панели чуть темнее фона, разделение
   1 px рамками, тень только у всплывающих (токены `--bg` #ffffff,
   `--bg-panel` #f7f7fa, `--border` #e4e4ec).
3. Акцент — градиент только у главного действия и активного чата; остальное
   приглушено; доля цветных пикселей кадра растёт за счёт содержимого
   (картинки, код, статусы), не за счёт декора.
4. Каждая строка списков — две линии: название и подпись/время/состояние.
5. Лента чатов сгруппирована по датам («Сегодня», «Вчера», «На этой неделе»).
6. Код-блок — тёмная плашка на светлой теме, кнопка «Копировать» видна без
   наведения.
7. Секции разбора сворачиваются; заголовок ступени пронумерован и остаётся
   видимым в свёрнутом виде.
8. Дерево файлов: папки раскрываются по стрелке, активный файл подсвечен,
   длинный путь усечён с «…».
9. Инструменты — строки с действием (кнопка или тумблер); «позже» для
   неустановленного инструмента — её отдельное состояние, а не заглушка ряда.
10. Статусы безопасности различимы цветом: разрешено / только путь проекта /
    заблокировано, у каждой строки — конкретное значение.
