композере, сворачиваемость вызовов инструментов**. Кусок 2 (основа) и кусок 3

Образцы, по убыванию веса:

Слова владельца (2026-10-07): «пока не похоже на наш пример, окно чата
перегружено, много неудобных моментов, не похоже на наш образец и на клод»;
«я скидывал референсы в картинках как хочу чтобы это выглядело». Слово
«перегружено» старше и сильнее прежних правил плотности ленты

Готово, когда: снимок окна чата принят владельцем против его кадров
(было / стало / образец). Не входит: смена трёхколонной раскладки, новые
функции (никаких аватаров, меток времени в ленте, карточек статистики);
сайдбар и правая панель не трогаются — их вид ведут свои паспорта.

## 1. Зачем окно

Пользователь разговаривает с моделью: читает ответ и пишет следующее сообщение.
Главное действие одно — **написать и отправить сообщение** (композер внизу).
Всё остальное — служебное: как модель работала, откуда ответ. Сейчас служебное
стоит наравне с разговором и окно «шумит». Цель: разговор читается как текст на
чистом листе (Клод), служебные строки сгруппированы в тихие свёрнутые шаги,
акцентных пятен — не больше трёх (бейдж модели, кнопка отправки, активный чат
в сайдбаре).

## 2. Что убрать, что сгруппировать, что остаётся на виду

| Убрать | Сгруппировать | Остаётся на виду |
|---|---|---|
| Подсказку под композером «Enter — перенос строки · Ctrl + Enter — отправить» — дубль placeholder'а; шорткат остаётся в самом поле | Сообщения — парами «вопрос → ответ» (ходами) с большим зазором между парами | Композер: «+», поле, градиентная «↑» |
| Панельную подложку и линию-границу над композером — он не панель, а поле на фоне окна | Строки вызовов инструментов и служебные строки — внутрь хода, с малым зазором | Название чата и бейдж модели в шапке |
| Акцентную заливку чипов «Sources used» — источники не действия | Кнопки плагинов шапки — в плотный ряд без обрезки, избыток — «+N» | Ступени разбора ответа (развёрнуты) и «Sources used» под ответом |
| Обрезку кнопок плагинов краем шапки (сейчас кнопки режутся пополам) | Служебную строку «Ответ модели получен» — внутрь хода, как сейчас | Ошибки — красным, целиком (потеря сообщения не тихая заметка) |

## 3. Раскладка

Каркас не меняется (DESIGN §5): сайдбар 240 px, центр тянется, правая панель
280 px; на 1024×640 сайдбар 200 px, панель — оверлей по `☰`. Меняется только
внутренность центра.

### 1440×900 — разговор (целевой кадр)

```
┌──────────┬────────────────────────────────────────────┬──────────────┐
│ Сайдбар  │ шапка: название ···· [GLM-5.3 High][плагины]│ Контекст…    │
│ 240 px   ├────────────────────────────────────────────┤ 280 px       │
│          │        ← воздух → ┌──────────────┐ ← →     │              │
│          │                   │ колонка 760  │         │              │
│          │                   │ Вопрос (пузырь справа) │  │              │
│          │                   │ ответ: текст…          │  │              │
│          │                   │ 1 Проблемы… (ступень)  │  │              │
│          │                   │ ✓ read · src/bridge.ts ▸ (шаг, свёрнут)│
│          │                   │ SOURCES USED [bridge.ts]│ │              │
│          │                   │      ← ход 32 px →      │ │              │
│          │                   │ следующий вопрос…       │ │              │
│          ├────────────────────────────────────────────┤              │
│          │        ┌ +  Напишите сообщение…       ↑ ┐  │              │
│          │        └──────────── 760 ───────────────┘  │              │
└──────────┴────────────────────────────────────────────┴──────────────┘
```

- Лента: сообщения стоят в **колонке чтения 760 px**, прижатой к центру;
  при 1440 по бокам колонки остаётся по 56 px воздуха внутри ленты.
- Композер стоит на той же колонке 760 px по центру — вопрос, ответ и поле
  ввода читаются одной линией.
- Шапка и композер — на фоне окна (`--bg`), без собственной панельной
  подложки; разделение с лентой — только воздух, у композера — рамка самого
  поля ввода.

### 1024×640 — минимум

Колонка чтения занимает всю ширину центра (760 не влезает — `max-width`);
шапка 48 px, кластер окна и `☰` возвращаются в шапку (как сейчас); композер —
та же колонка во всю ширину центра; подсказки нет ни при каком размере.

## 4. Воздух и ритм сообщений

Все числа кратны шагу 4 px; значения — токены, кроме отмеченного.

| Что | Значение | Было | Откуда |
|---|---|---|---|
| Зазор между ходами (вопрос→ответ парами) | **32 px** | 16 | **моё, нет в DESIGN §4**: новый токен `--space-6: 32px` в `tokens.css` (кратен 4). Привести §4 при `/studio/done` |
| Зазор внутри хода (вопрос, вызовы, ответ, источники) | 8 px (`--space-2`) | 16 | §4; ход — одна группа |
| Поля ленты | 24 px (`--space-5`) | 24 | без изменений |
| Колонка чтения | `max-width: 760px`, по центру | нет (вся ширина) | **моё**: приём «узкая колонка чтения» (Клод); DESIGN ширины колонки не знает |
| Пузырь вопроса | радиус **16 px** (`--radius-lg`), паддинг 8×12, ширина ≤75 % колонки | радиус 10, 8×12, 85 % | DESIGN §4 прямо: «пузыри сообщений 16 px» — нынешний радиус был отступлением |
| Ответ модели | текст без плашки, 14 px / 1.5, во всю колонку | так же | §3, без изменений |
| Абзац внутри ответа | перенос `pre-wrap` + `overflow-wrap: anywhere` | есть | без изменений (крайний случай — слово на 400 знаков) |

Ход — строки от вопроса владельца до следующего вопроса (та же группировка,
что уже считает `sourceBlocks` в `src/sources.ts`). Строки до первого вопроса
(«Сервер недоступен…») — своя группа. Ходы не рисуют рамок и плашек — воздух
сам делит разговор.

## 5. Шапка — минимум хрома

| Что | Как |
|---|---|
| Высота | 48 px, линия снизу 1 px `--border` — без изменений (совпадение строк с правой панелью) |
| Фон | `--bg` (фон окна) вместо `--bg-panel` — **моё**: у образцов полоса над разговором не светлей содержимого; панели-«светлости» остаются у сайдбара и правой панели |
| Название чата | 15 px / 600 слева, усечение с «…» — без изменений; область перетаскивания окна сохраняется |
| Бейдж модели | как есть: пилюля с полупрозрачным фоном акцента и градиентной рамкой (записано «так» в DESIGN §7) — это вход панели сравнения, не шум |
| Кнопки плагинов | ряд справа от бейджа; **ни одна кнопка не обрезается краем**: пока помещаются — видны все; первая непомещающаяся и хвост сворачиваются в бейдж «+N», клик по нему открывает существующую панель «Плагины этого чата» (решение владельца 2026-10-04 «компактно, при переполнении +N» — сейчас вместо «+N» сделана обрезка, это defect вида). На кадрах фикстур (≤3 кнопки) «+N» не появляется |
| `☰` и кластер окна | как сейчас: только при ширине < 1200 px |

## 6. Композер — минимум хрома

| Что | Как |
|---|---|
| Подложка полосы | `--bg`, линия-граница сверху **удаляется** — **моё**: композер не панель; его отделяет воздух и рамка самого поля |
| Поле ввода | `--bg-input`, рамка 1 px `--border-strong`, радиус 16 (`--radius-lg`), фокус — рамка `--accent`; ширина — колонка чтения 760 px по центру; растёт с текстом до 160 px — без изменений |
| «+» | 32×32, призрачная, приглушённая — без изменений; меню «+», пикеры и оверлеи — якорятся как сейчас (`position: relative` остаётся) |
| «↑» | 32×32, градиент + свечение (выбранный вариант B тёмной темы), выключена на пустом поле с причиной в подсказке — без изменений |
| Подсказка под полем | **удаляется** (строка и её `@media`): шорткан уже в placeholder'е; на низком окне место не тратится |
| Чипы файлов | над полем, внутри полосы композера, приглушённые — без изменений |

## 7. Вызовы инструментов — свёрнутые шаги

Сейчас строка вызова — всегда развёрнутый моно-текст между вопросом и ответом:
механика заслоняет разговор. У образца работа модели — тихие свёрнутые строки,
которые раскрываются по клику.

| Что | Как |
|---|---|
| Свёрнутый шаг | одна тихая строка: знак статуса + текст вызова + чеврон `▸`; моно 12 px, текст `--text-dim`; паддинг 4×8, радиус 6; наведение — `--bg-hover` |
| Знак статуса | `✓` — `--success`, `⚠` — `--warning`, `⧗` — `--text-dim` и медленно пульсирует (прозрачность 0.5↔1, ~1.2 с) — работает; при замене строки на `✓` пульс пропадает (**моё**: статусные цвета §2 разрешены tool-строкам, акцентом не являются) |
| Раскрытие | клик по строке (и Enter/пробел с клавиатуры): под строкой те же детали моно 12 — у вызова плагина панель «Плагин / Чат / Скилл / Модель» (как сейчас), у вызова с файлом — полный путь файла; повторный клик сворачивает |
| Честность | раскрывается только то, что строка знает: нет ни файла, ни плагина — чеврона и клика нет, строка просто тихий шаг (выдуманных деталей нет) |
| По умолчанию | свёрнут; бегущий `⧗` тоже свёрнут — прогресс виден знаком; вариант «⧗ развёрнут» уходит в ось §14 |
| Ступени ответа | `StepSection` не меняется: заголовки ответа остаются развёрнутыми ступенями с номерами — это разговор, не механика |
| Служебные строки | «Ответ модели получен» — внутри хода как сейчас; ошибки («Сообщение не ушло», «Сервер недоступен») — красным целиком, не сворачиваются |

## 8. Источники — тише

Блок «Sources used» под ответом остаётся (источник должен открываться, а не
только называться), но перестаёт светиться:

- заголовок `Sources used` — 11 px, caps, `letter-spacing: 0.08em`, `--text-faint` (метки §3);
- чипы — фон `--bg-panel-2`, рамка 1 px `--border`, моно 12 px; наведение — рамка `--accent`;
  акцентная заливка `--badge-bg` убирается — **моё**: §1 «не больше двух акцентных
  пятен», источники — не действия первого порядка;
- ширина блока — колонка чтения (не 85 %), длинное имя файла — усечение с «…», полный путь в `title`.

## 9. Настоящие данные

| Случай | Данные | Как ведёт себя |
|---|---|---|
| Самый короткий вопрос | «Ок» | пузырь-точка справа, не растягивается |

| Самый длинный разговор | 100 строк (фикстура `?состояние=много`) | ходы по 32 px, лента не тормозит (проверка «много» зелёная) |
| Вызовы | `⧗ read` (бегущий), `✓ read · src/bridge.ts` (с файлом), вызов плагина `⧗ …` | все — свёрнутые шаги; у первого деталей нет (честно), у остальных раскрываются |

## 12. Тексты (дословно)

- placeholder поля: `Напишите сообщение… (Ctrl + Enter — отправить)`
- подсказка `Enter — перенос строки · Ctrl + Enter — отправить` — удаляется, нигде не остаётся
- `title` «+»: `Добавить`; «↑»: `Отправить` / `Отправляется` / `Напишите сообщение — отправлять нечего`
- шаг вызова: текст строки без изменений (`⧗ read`, `✓ read · src/bridge.ts`), `title` строки `Детали вызова`
- бейдж переполнения: `+N`, `title` `Плагины этого чата`
- источники: заголовок `Sources used`, `title` чипа `Открыть {путь} в дереве`

## 13. Порядок обхода с клавиатуры

Сверху вниз: бейдж модели → ряд плагинов шапки (кнопки, затем «+N») → (`☰` на
узком окне) → ступени ответа → шаги вызовов (Tab до строки, Enter/пробел —
раскрыть) → чипы источников → «+» → поле ввода → «↑». Оверлеи (сравнение,
меню «+», панель плагинов) — свои существующие циклы и возвраты фокуса, без
изменений.

## 14. Куски 2–3: что разводится по вариантам плотности и шапки

Эта спецификация фиксирует базовую линию; кусок 3 строит по ней 2–3 варианта
и лист сравнения с кадрами владельца. Оси, по которым варианты расходятся
(база = значения этой спеки):

| Ось | База (здесь) | Чем варьировать |
|---|---|---|
| Плотность ленты | ходы 32 px, колонка 760 px | ходы 24 или 16 px; колонка 860 px или вся ширина центра |
| Шапка | фон `--bg`, бейдж с градиентной рамкой, ряд плагинов + «+N» | фон `--bg-panel`; бейдж-тихая пилюля без градиента; кнопки плагинов — одна кнопка «Плагины» с меню (второстепенное в меню — кусок 2) |
| Сворачиваемость вызовов | всегда свёрнуты, `⧗` пульсирует | свёрнуты после завершения, `⧗` развёрнут с деталями (вариант из паспорта Клода) |
| Композер | колонка 760 px, подсказки нет | вся ширина центра; вернуть подсказку вторым вариантом |

Кусок 2 (основа) реализует базу этой спеки; если владелец на листе выберет
другой вариант строки оси — меняются значения, не структура.

## 16. По чему судить снимок

1. Сообщения стоят в колонке ≤760 px по центру; между краем ленты и текстом —
   воздух (при 1440 по 56 px), текст не прижат к границам панелей.
2. Ходы разговор разделены зазором заметно больше, чем строки внутри хода
   (32 против 8): глаз видит пары «вопрос → ответ» без линеек и рамок.
3. Вопрос — пузырь справа с радиусом 16; ответ — чистый текст без плашки;
   «Ответ модели получен» — тихая моно-строка внутри хода.
4. Вызов инструмента — свёрнутая тихая моно-строка со статусным знаком
   (`✓` зелёный, `⧗` пульсирует) и чевроном; раскрывается кликом; деталей без
   данных не выдумано.
5. «Sources used» — caps-подпись 11 px, чипы без акцентной заливки; акцентных
   пятен в центре окна два: бейдж модели и кнопка отправки.
6. Шапка: фон как у окна, название слева, бейдж и плагины справа, ни одна
   кнопка не обрезана; подсказка под композером отсутствует.
7. Композер — одно поле с «+» и «↑» на колонке чтения, без линии-границы
   и панельной подложки; фокус поля подсвечивает рамку.
8. Тёмный и светлый кадры совпадают по раскладке попиксельно, различие —
   только цвета токенов.
9. 1024×640: колонка во всю ширину центра, шапка 48 px, `☰` и кластер окна
   на месте, композер и шаги не сломаны.
10. Пустой чат — приветственная сборка прежняя, колонка чтения её не трогает;
    ни одного сырого цвета вне `tokens.css`.
