# DESIGN — дизайн-система GnomeCode

DT9 (хвост юнита «Глубина плагинов»). Фиксирует систему как она есть в
коде: токены, каркас, компоненты, правила. Новое из B10 — rail, stats-bar,
радар, фейловер, гейт включения — включено сюда.

## Токены

`src/styles/tokens.css` — единственный источник цветов и размеров:

- Фон/панели: `--bg-panel`, `--bg-panel-2`, `--bg-input`, `--bg-hover`,
  `--bg-raised`
- Текст: `--text`, `--text-dim`, `--text-faint`
- Смысловые: `--accent` (выбор/фокус), `--success`, `--warning`, `--danger`
- Бейджи: `--badge-bg`, `--badge-border`
- Границы: `--border`, `--border-strong`; радиусы `--radius-sm|md`;
  тень `--shadow`; `--font-mono`; `--sidebar-w` (+`--sidebar-w-narrow`)
- Темы: тёмная и светлая — только через токены, никаких хардкод-цветов
  в компонентах.

## Каркас окна (B10)

1. **icon-rail** (`Rail`, 68px) — логотип, разделы, «Быстрые действия»;
   активный раздел — `rail__item--active`. Разделы, чьих страниц нет,
   ведут в ближайший экран.
2. **Колонка «Чаты»** (`Sidebar`) — поиск, шапка «Чаты [+][🗄]», разделы
   Проекты/Закреплённые/группы дат/Архив; подвал без темы и аккаунта.
3. **Центр** (`ChatView`) — `StatsBar` → `ChatHeader` → лента → композер.
4. **Правая панель** (`ContextPanel`, оверлей) — Контекст проекта,
   Инструменты, Безопасность этого чата.

Страницы (Статистика/Плагины/Настройки) заменяют центр целиком,
управление окном (`WindowCluster`) остаётся в шапке каждой.

## Правила

- **Честные данные**: строка не показывает то, чего не знает (прочерк с
  причиной, «нет данных», фолбэк-точка радара помечена). Квоты и лимиты
  не выдумываются.
- **Только токены**: цвета/отступы — из tokens.css; семантические цвета
  (danger/success/warning) — для статусов, не для декора.
- **Глифы, не эмодзи**: статусы ленты — `✓ ⚠ ✗ ⧗`; карточки-заготовки —
  инициалы; иконки rail — пока текстовые, замена на SVG не меняет разметку.
- **Клавиатура**: у интерактива — `:focus-visible` (accent, offset 2px);
  Esc закрывает оверлей; строки-кнопки — `div[role=button]` + Enter/пробел
  (button в button запрещён — XT-fix).
- **Тосты** — сверху по центру (композер снизу не перекрывать).
- **Компактность**: шрифты 11–14px, отступы токенами (--space-*).
