# Интерфейс

Правила для всего, что пользователь видит и нажимает. По этому документу
`designer` пишет спецификацию экрана, цепочка `executor` (`executor-code`)
её реализует, `reviewer`
сверяет снимок. Чего здесь нет, то решается на глаз — и потом плывёт, поэтому
найденное на глаз записывается сюда.

Источник character: референсы владельца — тёмная тема («Codexis») и светлая
(«OpenCode PRO»); карта образцов — `docs/refs/INDEX.md` (файлы референсов
ждут владельца). Все значения — из токенов `src/styles/tokens.css`; сырые
цвета в компонентах запрещены.

## 1. Характер

- **Спокойный** — на экране не больше двух акцентных пятен: активный чат в
  сайдбаре и главная кнопка действия; всё остальное — приглушённые цвета.
- **Плотный** — базовый размер текста 14 px, наименьшая высота строки 1.4,
  отступы без воздуха, панели разделены 1 px рамками, не тенями.
- **Техничный** — моно-шрифт для кода, чисел и tool-строк ленты.

## 2. Цвет

Обе темы равноправны; значения ниже — тёмная (референс «Codexis»), светлая —
в том же файле рядом.

| Роль | Цвет (тёмная) | Где задан в коде |
|---|---|---|
| фон | `#0a0e1a` — `--bg` | `src/styles/tokens.css` |
| подложка панели | `#101627` — `--bg-panel`; вторичная `#161e33` — `--bg-panel-2` | там же |
| рамка, разделитель | `#232d47` — `--border`; сильная `#303c5e` — `--border-strong` | там же |
| текст основной | `#e6eaf5` — `--text` | там же |
| текст приглушённый | `#8b94ad` — `--text-dim`; слабый `#5a637d` — `--text-faint` | там же |
| акцент | градиент `#4f7cff → #6d5cff → #9d5cff` — `--accent-gradient` | там же |
| опасность / успех / предупреждение | `--danger` / `--success` / `--warning` | там же |

Правило акцента: акцент — только у действий пользователя и активного
состояния (главная кнопка, активный чат, кнопки плагинов в шапке).
Статусные цвета tool-строк (`✓`/`⚠`) — не акцент.

## 3. Типографика

| Роль | Шрифт | Размер | Где |
|---|---|---|---|
| заголовок окна/чата | Segoe UI, 700 | 15 px | `--font-ui` |
| заголовок раздела | Segoe UI, 600 | 13 px, caps 11 px для меток | |
| заголовок пустого состояния | Segoe UI, 700 | 20 px | центр ленты (пункт 4) |
| логотип в сайдбаре | Segoe UI, 700 | 15 px | рядом со знаком (пункт 4) |
| основной текст | Segoe UI, 400 | 14 px / 1.5 | |
| подпись, число | Segoe UI, 400 | 11–12 px | |
| код, tool-строки | Cascadia Code / Consolas — `--font-mono` | 12 px | |

Наименьший читаемый размер на минимальном экране (1024×640): 11 px.

## 4. Сетка и отступы

- базовый шаг: **4 px** (`--space-1…5`: 4/8/12/16/24); все отступы кратны ему;
- поля окна 16 px, зазор между карточками 8–12 px, внутренние отступы кнопки 8×12 px;
- радиусы: 6 px мелочи, 10 px кнопки и панели, 16 px пузыри сообщений (`--radius-*`);
- наименьшая цель для нажатия: 32×32 px (кнопки композера).

## 5. Экраны и раскладка

- Целевой размер: 1440×900 (окно по умолчанию); минимум 1024×640 (`tauri.conf.json`).
- Три колонки: сайдбар 240 px (фикс), чат (тянется), правая панель 280 px (фикс).
- При ширине < 1200 px правая панель — оверлей 280 px по кнопке `☰` шапки,
  начинается **под** шапкой (`top: 48px`), поэтому `☰` и переключатель темы
  остаются доступны; сайдбар — не уже 200 px (`--sidebar-w-narrow`).
- Обе темы переключаются без перезапуска; ни один цвет компонента не задаётся мимо токенов.

## 6. Состояния

У каждого интерактивного элемента описаны **все**: обычное, наведение
(`--bg-hover`), нажатие, фокус с клавиатуры, выключенное (и **почему**
выключено — причина на самом элементе), загрузка. У каждого экрана: пусто
(Home state референса), ошибка, очень много данных (длинный чат — лента не
тормозит; длинное имя файла — усечение с «…»), очень длинный текст (перенос,
не горизонтальный скролл).

Обязательно для новых элементов: кнопка плагина в шапке (обычное / hover /
активный плагин / отключён для чата), пункт меню «+», кнопка отправки
(обычное / пустой ввод — выключена / отправка — стоп).

## 7. Так и не так

| Так | Не так | Почему |
|---|---|---|
| Три колонки, чат в центре, референсная иерархия | generic IDE-dashboard, сетка панелей на весь экран | слова владельца: «preserve their layout philosophy… do not redesign into a generic IDE dashboard» |
| Бейджи-кнопки плагинов в шапке чата, компактно, при переполнении «+N» | ряд крупных кнопок над лентой или постоянные кнопки в композере | решение владельца (2026-10-04); спека: «Do not overcrowd the composer» |
| Тень `--shadow` только у всплывающих (меню «+») | тени на панелях | панели разделяются рамками — плотный характер |

Пополняется после каждой поправки владельца по виду: поправка, сделанная
дважды, — это правило, которого здесь не хватает.

## 9. Словарь контекста (решение владельца, 2026-10-04)

Обязательные термины интерфейса — везде одинаково, без синонимов:

| Значок | Термин | Смысл для пользователя |
|---|---|---|
| 📌 | **Pinned** | важно прямо для текущей работы |
| 🧠 | **Knowledge** | проект должен помнить это в будущем |
| ⚙ | **Skill** | проект знает, как это делать |
| 📦 | **Artifact** | результат уже выполненной работы |
| 📚 | **Archive** | старая история, которую можно достать при необходимости |

Подробности — `docs/SPEC/context.md`, раздел L.

что готовые не подходят.
